The World, Today — one newspaper front page for Sunday 22 November 2026, carrying 48 stories from the day: a COP31 deal taking shape in Antalya, Iranian strikes on Bahrain and tankers burning near Hormuz, the capture of "El Chapo Isidro" in Sinaloa, and 45 further stories from world news, business, technology, science, sport and culture.

`entry.png` holds the finished page, rendered in advance. `main.py` does nothing but copy that file to the grader's output directory and verify the copy byte for byte. It needs only the Python standard library — no network, no clock, no randomness — so running it twice produces identical bytes.

## Running it

```sh
python3 main.py   # writes /output/entry.png
```

The picture lands at `/output/entry.png`, or at `$MAKEFUN_OUTPUT_DIR/entry.png` when that variable is set. It is a 1024x1024 PNG of 187,127 bytes, well under the 1 MiB limit.
